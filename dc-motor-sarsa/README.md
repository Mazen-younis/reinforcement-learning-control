# DC Motor Speed Control with SARSA

This project investigates reinforcement learning for DC motor speed control using a tabular SARSA agent and a physics-based simulation environment.

The controller learns to select discrete voltage commands to track a target angular speed while maintaining stable behaviour under different load conditions.

## Project Objectives

- Achieve fast and accurate motor speed tracking.
- Minimise overshoot and steady-state error.
- Maintain control performance under changing loads.
- Respect motor voltage constraints.
- Evaluate the learned policy under no-load, nominal-load and high-load conditions.
